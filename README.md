# 🏋️ Fitness Tracker App

A clean and responsive fitness tracking web application built with **React and Vite**. The app allows users to record their daily fitness activities and monitor their progress through an easy-to-use dashboard.

## ✨ Features

* 👣 Track daily steps
* 🔥 Track calories burned
* ⏱️ Record workout duration
* 🏃 Add different types of exercises
* 📊 View fitness progress
* 📋 View recent activity history
* 💾 Save fitness records using Local Storage
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* React
* Vite
* JavaScript
* CSS
* Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shrijadhav497/fitness-tracker-app.git
```

### 2. Navigate to the project

```bash
cd fitness-tracker-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.

## 💾 Data Storage

The application uses **Browser Local Storage** to save fitness activity records. This allows the data to remain available even after refreshing or reopening the application.

## 🎯 Project Objective

The goal of this project is to provide users with a simple way to track their daily fitness activities and monitor their progress through a clean and intuitive interface.
